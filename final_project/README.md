# Чат-бот на базе Yandex GPT

Итоговый проект: консольный бот, который умеет общаться, запоминать контекст и даже обрабатывать локальные файлы.

## Что умеет бот:
Диалог с контекстом:
Бот помнит предыдущие сообщения (лимиты настраиваются).

Работа с файлами:
Можно вставить содержимое файла прямо в запрос с помощью тега `@::путь_к_файлу::`.

Массовая обработка:
Команда `/file_chunk` позволяет делить большие файлы на части и обрабатывать их по очереди.

## Как запустить:
1. Установите зависимости: pip install -r requirements.txt
2. Создайте файл .env в корне и добавьте туда:
   env
   YANDEX_API_KEY=ваш_ключ
   YANDEX_FOLDER_ID=ваш_id
3. Проект поддерживает два способа конфигурации (еще config.yaml). Если параметр указан в обоих местах, приоритет отдается переменным из .env
4. Потенциально в config.yaml "не секретные":      
limit_message:    
limit_chars:   
temperature:   
system_prompt:


5. А в .env - секретные:   
YANDEX_API_KEY=ваш_ключ
YANDEX_FOLDER_ID=ваш_id
